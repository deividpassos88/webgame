⚠ Menu ADM liberado por padrão neste build

src/main.ts calcula adminEnabled = !(admin === '0' || admin === 'false' || VITE_ADMIN_MODE === 'false'). Na prática o botão flutuante ADM aparece para qualquer visitante — inclusive no build gerado por npm run build — e o modo admin do Vite não muda mais isso. Para abrir o jogo sem ADM use ?admin=0; para publicar sem as ferramentas, ajuste src/main.ts.
