# Blender Human Base Meshes source

`blender_human_male_cc0.blend` contains a reduced, game-oriented derivative of
the **Realistic Male Body** and paired eyes from **Human Base Meshes v1.4.1** by
Blender Studio and community contributors.

- Source: https://www.blender.org/download/demo-files/
- License: Creative Commons Zero v1.0 Universal (CC0-1.0)
- Local changes: base-resolution extraction, uniform height normalization to
  1.85 m, and deterministic face-set-guided conversion from A-pose to T-pose.

No texture files from the bundle are embedded. The local blend uses procedural
materials created by this project.
